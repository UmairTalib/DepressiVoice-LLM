Methodology

Pipeline Overview

``` Master Audio → Diarization (Pyannote 3.1) → Role Assignment (Anchor + Duration) → Patient Audio Extraction → Transcription (Whisper large-v3) → Validation ```

Key Innovations

1. Duration-Based Patient Selection - ELLIE assigned by max similarity to biometric anchor - PATIENT assigned by max speaking duration (not similarity) - Handles female-female pairs where similarity is ambiguous

2. Confidence Scoring - Margin = similarity_diff(ELLIE, PATIENT) - HIGH: margin ≥ 0.2 (74.2% of sessions) - MEDIUM: 0.1 ≤ margin < 0.2 (12.4%) - LOW: 0.05 ≤ margin < 0.1 (5.1%) - VERY_LOW: margin < 0.05 (8.0%)

3. Quality Flagging - Automatic flag for margin < 0.1 - Documents reason, review recommendation - 37/275 sessions flagged (13.5%)

Scripts & Implementation

Core Pipeline: src/phase1_pipeline_rerun.py

Function: assign_roles() (Lines 81-172)

Purpose: Assign ELLIE/PATIENT labels with confidence scoring

Logic: 1. Extract speaker embeddings for all detected speakers 2. Calculate cosine similarity to Ellie anchor 3. ELLIE = argmax(similarities) ← Speaker most similar to anchor 4. Calculate duration for ALL other speakers
5. PATIENT = argmax(durations, excluding ELLIE) ← Longest-speaking non-Ellie 6. Compute margin = sim[ELLIE] - sim[PATIENT] 7. Assign confidence level based on margin 8. Return roles, similarities, metadata

Rationale: Similarity identifies Ellie (consistent voice), duration identifies patient (talks more in interview).

Function: extract_patient_audio() (Lines 174-206)

Purpose: Extract and concatenate patient speech segments

Process: - Filter diarization for patient label - Extract waveform segments from master audio - Convert stereo → mono if needed - Concatenate all segments - Save as patient_audio.wav

Function: save_diarization_results() (Lines 208-262)

Purpose: Save outputs with quality flags

Outputs: - XXX.rttm - Diarization segments - roles.json - Roles + confidence + margin + durations - quality_flag.json - If confidence LOW/VERY_LOW - Logs all actions

Failure Modes & Limitations

Known Issues

1. Single Speaker Detection (Session 309) - Symptom: Only 1 speaker detected - Frequency: 1/275 (0.4%) - Mitigation: Forced 2-speaker rescue - Status: Resolved

2. Low Biometric Separation (Female-Female) - Symptom: Margin < 0.05, high uncertainty - Frequency: 22/275 (8.0%) - Mitigation: Duration-based selection + quality flags - Validation: All 22 checked, duration ratio >2.0 confirms correct assignment

3. Transcript Contamination - Symptom: Interviewer prompts in patient text - Frequency: 3% sessions >5% contamination - Mitigation: VAD filtering - Future: Text cleaning pipeline

Limitations

1. Timestamp Alignment - Transcripts aligned to patient_audio.wav, not master - Can map back using RTTM if needed

2. Variable Contamination - 3% sessions need text cleaning

3. Biometric Anchor Generalization - Single anchor may not capture all Ellie voice variations
